# Liana Tatli — сайт-магазин (макет)

Статичный сайт: `index.html`, `css/style.css`, `js/app.js`, фото в `img/`.
Открыть локально — просто `index.html` в браузере.

- Каталог и цены — массив `PRODUCTS` в `js/app.js` (поле `img` — фото, `art` — иллюстрация-заглушка, `price: null` — «цена по запросу»).
- Отзывы в коробочке — массив `REVIEWS` в `js/app.js`.
- Заказ из корзины уходит готовым сообщением в WhatsApp (`WHATSAPP` в `js/app.js`).
